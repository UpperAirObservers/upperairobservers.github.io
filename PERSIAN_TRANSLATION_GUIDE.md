# Persian translation editing

The site now uses **separate static Persian pages under `/fa/`** for bilingual Google SEO.

Edit Persian visible text directly in:

- `fa/index.html`
- `fa/digisonde.html`
- `fa/ground-station.html`
- `fa/digimon.html`

If you change the subject or meaning of a page substantially, also update that page's Persian `<title>`, `<meta name="description">`, Open Graph description, and JSON-LD description so the SEO metadata remains consistent with the visible content.
