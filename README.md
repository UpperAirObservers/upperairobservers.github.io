# Upper Air Observers production website (V2)

This version includes:
- self-hosted Persian font files for reliable GitHub Pages rendering
- added DigiMon ground-check screenshot
- added runway comparison photo
- added two high-altitude / near-space DigiSonde photos

## GitHub Pages
Upload the full contents of this folder into the repository root of:
`upperairobservers.github.io`

Then in GitHub:
- Settings -> Pages
- Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

## Notes
The Persian font is bundled locally in `assets/fonts/`, so the site does not depend on Google Fonts for Farsi text.
