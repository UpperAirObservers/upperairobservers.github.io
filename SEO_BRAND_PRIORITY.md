# Brand-priority SEO changes

This version strengthens the Persian brand query **پایشگران جو بالا** and the DigiSonde spelling variants **دیجی سوند**, **دیجی سوند**, **دیجی سوند**, and **DigiSonde** without hiding text or using keyword stuffing.

After deployment:

1. In Google Search Console, inspect and request re-indexing for:
   - https://upperairobservers.github.io/fa/
   - https://upperairobservers.github.io/fa/digisonde.html
2. Keep the LinkedIn company name and website consistent with **Upper Air Observers | پایشگران جو بالا** and link back to the website.
3. In Search Console > Performance > Search results, monitor these queries:
   - پایشگران جو بالا
   - دیجی سوند
   - دیجی سوند
   - دیجی سوند
   - DigiSonde
4. Do not repeatedly resubmit unchanged pages. Allow Google time to recrawl and reprocess the content.
5. Natural links from relevant meteorological, industrial, partner, exhibition, research, or company-profile websites are the strongest next step for the branded query.

No SEO change can guarantee a #1 ranking; Google determines ranking. This package is optimized to make the Persian homepage the clearest entity page for the company name and the DigiSonde page the clearest page for all common Persian spellings of the product.
